# 第一次使用 2.1

1. 按 [安装说明](../INSTALL.md) 安装 md2wechat；已有配置只检查版本并校验，不重复初始化。
2. 安装插件后，打开文章和“公众号排版”面板，先预览当前文章，确认排版服务可用。
3. 需要创作助手时，主动选择已安装的 Claude Code 或 Codex，完成插件内连接测试。不使用助手也可继续原有预览和草稿流程。
4. 选择基础排版或智能增强，查看候选和展示变化，再采用。需要时润色正文或调整段落展示。
5. 在标题或封面窗口生成候选、查看批次并选中。选中即保存为本篇发布资料；换一批不会取消已有选择。
6. 正文配图另行选择段落，选择已有图片或生成候选，再点击插入。图片进入公众号成稿，原始笔记不会被改写。
7. 查看发布前检查，确认账号、标题、封面等信息，最后创建草稿。此操作不等于正式发布文章。

图片只使用现有 md2wechat 火山生图配置。每次生成 2 张，会发送相应内容并可能产生费用；生成前阅读说明。未确认创建草稿前，不上传微信图片。

原文更新后旧成稿保留供比较，暂停创建草稿。重新排版并采用后才恢复；刷新预览不会修改微信后台旧草稿。创建结果不确定时先核对公众号后台，不能反复点击。

外部 Agent 技能接入仍可用，但需要官方 Obsidian 命令行和包内技能；插件内 Claude Code/Codex 连接不依赖该命令行。桌面进程不会自动执行终端函数，请以插件内连接结果为准。

2.1.0 主要宿主流程已完成实际检查，已测操作与剩余边界见[宿主验收记录](verification/creation-host.md)和[兼容范围](AGENT-COMPATIBILITY.md)。

图片生成前可选择“图片风格”，并查看对应说明。正文配图提供全部可用风格，信息图排在前面；封面提供适合封面的方案，也包括兼容封面的苹果发布会、暗黑票券和复古版画风格。选择会记住，实际生成使用所选方案。本机 md2wechat 3.5.0 当前发现 25 种正文配图风格和 14 种封面风格，后续以工具返回的列表为准。信息图可使用原段落已有文字，不应增加原文没有的事实或数据。
