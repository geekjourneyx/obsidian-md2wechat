# 第一次使用

这是桌面端候选版，需要 Obsidian 与安装程序均为 1.12.7 或更新版本。

1. 安装插件的 `main.js`、`manifest.json`、`styles.css`，在 Obsidian 第三方插件中启用。
2. 在 Obsidian 设置 → 关于（部分语言显示常规）→ 高级中启用命令行界面。按宿主提示注册 `obsidian` 命令。
3. 安装并配置现有 md2wechat。先确认它可以预览一篇文章。插件不要求填写接口地址或密钥。
4. 把随项目提供的 `skills/obsidian-md2wechat` 按你所用 Agent 的技能安装方式放入技能目录。也保留现有 md2wechat 技能。
5. 打开文章，对 Agent 说：“排版 Obsidian 当前文章，完成后展示给我。”若同时打开多个笔记库，请说明笔记库名称。
6. 结果自动出现在 Obsidian 的公众号排版面板。检查正文，必要时调整主题或字号；点击创建草稿，选账号和封面，最后确认。

“先预览当前文章”只进行已有内容预览，不代表 Agent 已经改进了排版。

文章改动后会保留上次排版，但不能直接创建草稿。请让 Agent 按新内容重新排版。创建结果不确定时先核对公众号草稿箱，不要反复点击。

原版插件保存的设置仍保留，候选版不会读取旧密钥进行直接转换，也不会将密钥自动搬入 md2wechat。
