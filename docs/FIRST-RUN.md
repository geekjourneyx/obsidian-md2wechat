# 第一次使用 2.0

1. 按 [安装说明](../INSTALL.md) 先安装 md2wechat，并执行版本检查、配置初始化及配置校验。
2. 安装 Release ZIP 中的插件文件夹，在桌面 Obsidian 第三方插件中启用。
3. 打开一篇文章，运行“打开公众号排版”，点击“先预览当前文章”，确认配置可用。
4. 如需 Agent 自动排版，启用 Obsidian 官方命令行，按宿主提示注册 `obsidian` 命令；安装随包提供的 `skills/obsidian-md2wechat`，也保留 md2wechat 自带技能。
5. 对 Agent 说：“排版 Obsidian 当前文章，完成后展示给我。”多个笔记库打开时，请说明笔记库名称。
6. 查看返回的正文，调整主题；字号和复制在“更多”中。原文更新后点“刷新排版”读取最新正文，或让 Agent 重新排版。
7. 点击“创建草稿”，选择账号和封面并确认。成功后弹框关闭，顶部记录创建状态并保留查看入口。

“刷新排版”沿用当前主题、字号重新预览原文，不会自动重复 Agent 对正文的改写，也不会更新微信后台旧草稿。“创建新版草稿”表示新增一篇草稿。

草稿记录随文章切换恢复。若微信没有返回真实草稿链接，入口显示“打开公众号后台”。创建结果不确定时先核对公众号草稿箱，勿反复点击。
